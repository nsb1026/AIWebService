Developer Guide: Semantic HTML5, Accessibility (a11y) & DOM Sanitization

HTML5 is the standard markup language for documents designed to be displayed in web browsers, specified by the WHATWG HTML Living Standard and W3C Recommendation.

1. Semantic Structure vs. Generic Div Containers

Modern web standards mandate semantic elements over non-semantic <div> tags:

  • <main>: Primary unique content area of the document (single instance per page).
  • <article>: Self-contained, independently distributable composition.
  • <section>: Standalone section of content grouped around a common topic with a heading.
  • <nav>: Navigation link container.

2. Web Accessibility (WCAG 2.2 & WAI-ARIA)

Accessible HTML ensures users with visual or physical impairments can navigate using screen readers and keyboards:

  • Every interactive element (button, link, form control) must have an accessible name via text content or aria-label.
  • Images must include descriptive alt text unless purely decorative.
  • Logical heading hierarchy (<h1> through <h6>) without skipping levels.

3. DOM-Based XSS & HTML Sanitization APIs

Rendering un-sanitized user HTML via innerHTML enables DOM-based XSS attacks. Modern browsers provide the Sanitizer API (or libraries like DOMPurify) to safely strip script tags and inline event handlers before DOM insertion.

Safe HTML Rendering Code Snippet

// JavaScript (DOMPurify HTML Sanitization)
import DOMPurify from 'dompurify';

const rawDirtyHtml = `<p>Hello <script>alert('xss')</script><img src=x onerror=alert(1)></p>`;
const cleanHtml = DOMPurify.sanitize(rawDirtyHtml);
// Result: "<p>Hello <img src=\"x\"></p>"

document.getElementById('content').innerHTML = cleanHtml;

HTML Formatter FAQ

Q: Why is having a single <h1> tag recommended for SEO?

A: Search engine crawlers inspect the primary <h1> tag to understand the core subject matter of the page. Having multiple or missing <h1> tags degrades SEO heading hierarchy.

Q: What are void elements in HTML5?

A: Void elements (e.g. <img>, <br>, <hr>, <input>, <meta>, <link>) cannot have child nodes and do not require closing tags in HTML5.
