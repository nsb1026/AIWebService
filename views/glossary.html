Technical Glossary

A comprehensive directory of modern web development and data engineering terminology.

JSON (JavaScript Object Notation)

A lightweight, text-based, language-independent data interchange format. It is easy for humans to read and write and easy for machines to parse and generate.

Base64 Encoding

An encoding scheme that represents binary data in an ASCII string format. Commonly used for embedding images or transmitting binary data over text-based protocols.

JWT (JSON Web Token)

A compact, URL-safe means of representing claims to be transferred between two parties. Used for authentication and information exchange.

XSS (Cross-Site Scripting)

A security vulnerability where an attacker injects malicious scripts into web pages. Prevention involves output encoding and input validation.

CORS (Cross-Origin Resource Sharing)

A mechanism that allows restricted resources on a web page to be requested from another domain outside the domain from which the first resource was served.

CSP (Content Security Policy)

An additional layer of security that helps detect and mitigate certain types of attacks, including XSS and data injection attacks.

Baseline

A set of web platform features fully supported by all major browser engines (Chrome, Firefox, Safari, and Edge). Ensures broad compatibility.

Core Web Vitals

A set of specific factors Google considers important in a webpage's overall user experience (LCP, FID, CLS).

PWA (Progressive Web App)

Web applications that use modern capabilities to deliver an app-like experience. Fast, reliable, and engaging.

WebAssembly (WASM)

A binary instruction format for a stack-based virtual machine, designed as a portable compilation target for high-level languages.
