Developer Guide: One-Way Hashing, HMAC & Password Security

A cryptographic hash function is a mathematical algorithm that transforms arbitrary data into a fixed-length string of hexadecimal characters. Hash functions are irreversible (one-way) and deterministic (the same input always produces the exact same hash output).

1. One-Way Hashing vs. Symmetric Encryption

Hashing (SHA-256): One-way data reduction. Original text cannot be decrypted back from the hash. Used for verifying file integrity and message signatures.

Encryption (AES-256): Two-way transformation. Ciphertext can be decrypted back to plain text using a secret key. Used for confidential data storage and transport.

2. What is HMAC (Hash-based Message Authentication Code)?

HMAC combines a secret cryptographic key with a hash function (e.g. HMAC-SHA256). It verifies both data integrity and authenticity, preventing attackers from tampering with API payloads during transmission over public networks.

3. Password Storage & Salting Rules

Never hash passwords using plain SHA-256 or MD5 due to vulnerability to pre-computed Rainbow Table attacks. Always use key-derivation algorithms with random salts like Bcrypt, Argon2id, or PBKDF2.

Generating Hashes & HMAC in Backend Languages

// JavaScript (Web Crypto API)
async function sha256(message) {
    const msgUint8 = new TextEncoder().encode(message);
    const hashBuffer = await crypto.subtle.digest('SHA-256', msgUint8);
    const hashArray = Array.from(new Uint8Array(hashBuffer));
    return hashArray.map(b => b.toString(16).padStart(2, '0')).join('');
}

# Python 3 (hashlib & hmac)
import hashlib, hmac

# Plain SHA-256
hash_val = hashlib.sha256("Hello World".encode('utf-8')).hexdigest()

# HMAC-SHA256
secret_key = b"secret_key_123"
hmac_val = hmac.new(secret_key, "Hello World".encode('utf-8'), hashlib.sha256).hexdigest()

Cryptographic Hash FAQ

Q: Is MD5 or SHA-1 safe for cryptographic security?

A: No. MD5 and SHA-1 have known collision vulnerabilities. Use SHA-256, SHA-512, or SHA-3 for modern security implementations.

Q: Is my secret key sent to any server when generating HMAC?

A: No. All computation utilizes the native browser Web Crypto API (window.crypto.subtle) locally.
