Developer Guide: Diff Algorithms, Git Unified Diffs & Code Review

Delta computation (finding differences between two sequences of symbols) is a cornerstone of version control systems like Git, Mercurial, and modern code review platforms.

1. The LCS & Myers Diff Algorithm

Diff tools rely on calculating the Longest Common Subsequence (LCS) between two inputs. Eugene Myers' algorithm (Myers Diff) solves this problem in $O(ND)$ time complexity, finding the shortest edit script that transforms sequence $A$ into sequence $B$ using insertions and deletions.

2. Git Unified Diff Format

Standard Git patch files use the Unified Diff format (git diff), which groups changes into unified chunks prefixed by @@ -start,count +start,count @@ headers. Added lines are prefixed with + and deleted lines with -.

3. Debugging API Payloads & Config Regressions

Comparing raw JSON API responses directly can be noisy due to variable key ordering. Sorting keys first (using our JSON Sort tool) before executing a diff isolates true semantic changes from superficial formatting variations.

Generating Diffs Programmatically

# Shell / Git Command Line
# Compare two files side-by-side
diff -u file_original.json file_modified.json

# Git diff ignoring whitespace
git diff -w branch1 branch2 -- path/to/file.js

// Node.js (diff npm package)
const Diff = require('diff');
const diff = Diff.diffLines('baseline text', 'modified text');
diff.forEach((part) => {
  const color = part.added ? 'green' : part.removed ? 'red' : 'grey';
  console.log(`%c${part.value}`, `color: ${color}`);
});

Diff Checker FAQ

Q: Is my source code uploaded to any server during comparison?

A: No. The entire diff computation runs inside your browser using client-side JavaScript. Proprietary code and private data never leave your computer.

Q: How does this tool handle whitespace differences?

A: The algorithm compares exact characters per line, making it easy to identify leading indentation changes, trailing spaces, or missing line breaks.
