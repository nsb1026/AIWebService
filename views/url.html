Developer Guide: The Anatomy of a Uniform Resource Locator (RFC 3986 & WHATWG)

A Uniform Resource Locator (URL) is a specific type of Uniform Resource Identifier (URI) that specifies where a resource is located on a computer network and the mechanism for retrieving it. The standard specification is defined by RFC 3986 and maintained by the WHATWG URL Standard.

1. Component Breakdown of a URL

Every standard Web URL consists of predictable functional parts:

  • Scheme (Protocol): Defines network protocol (e.g. https:, http:, ftp:, mailto:, wss:).
  • Authority (Host & Port): Specifies domain name or IP address (e.g., api.example.com) and explicit port (e.g. 8443).
  • Path: Hierarchical path pointing to specific resource endpoint (e.g. /v1/users/profile).
  • Query String: Key-value parameter pairs starting after ? and separated by &.
  • Fragment (Hash): Internal location identifier starting after #, processed solely client-side by web browsers.

2. Query String Normalization & Encoding Rules

Query parameters often carry special characters (spaces, quotes, non-ASCII symbols). Unreserved characters (A-Z, a-z, 0-9, -, _, ., ~) remain plain, while all other characters are percent-encoded (e.g., space becomes %20 or +).

3. Security Consideration: Open Redirects & SSRF

Parsing hostnames accurately is critical for defensive programming. Malicious URLs with tricky userinfo syntax (e.g., https://trusted.com@attacker.com) can bypass naive string checking. Always use standard URL parsing libraries to extract the true hostname.

URL Parsing Snippets in Native Languages

// JavaScript (WHATWG URL API)
const parsedUrl = new URL("https://api.example.com/search?q=json&page=2#top");
console.log(parsedUrl.hostname); // "api.example.com"
console.log(parsedUrl.searchParams.get("q")); // "json"
console.log(parsedUrl.pathname); // "/search"

# Python 3
from urllib.parse import urlparse, parse_qs
parsed = urlparse("https://api.example.com/search?q=json&page=2#top")
params = parse_qs(parsed.query) # {'q': ['json'], 'page': ['2']}

// Go (Golang)
package main
import (
    "fmt"
    "net/url"
)
func main() {
    u, _ := url.Parse("https://api.example.com/search?q=json&page=2#top")
    fmt.Println("Host:", u.Host, "Query:", u.Query().Get("q"))
}

URL Parsing FAQ

Q: What is the difference between URI, URL, and URN?

A: URI is the overarching identifier category. A URL specifies how to locate the resource (location + protocol), whereas a URN specifies a resource by name in a given namespace (e.g. urn:isbn:0451450523) regardless of location.

Q: Are query parameter keys case-sensitive?

A: Standard specifications treat query parameter strings as case-sensitive, though individual backend framework routers decide how they interpret query keys.
