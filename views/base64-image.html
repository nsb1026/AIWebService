Developer Guide: Data URIs (RFC 2397), Base64 Magic Bytes & Performance

Defined by RFC 2397, the data: URI scheme allows resource creators to embed small files inline in HTML, CSS, or JSON payloads instead of initiating separate HTTP fetch requests.

1. Data URI Structure & Syntax

A standard Data URI follows this format:

data:[<mediatype>][;base64],<data>

2. Base64 Magic Byte Fingerprinting

Image formats can be identified by the opening characters of their Base64 encoded payload ("Magic Bytes"):

  • PNG: Starts with iVBORw0KGgo... (Header \x89PNG\r\n\x1a\n)
  • JPEG: Starts with /9j/4... (Header \xFF\xD8\xFF)
  • GIF: Starts with R0lGODlh... or R0lGODlh... (Header GIF87a or GIF89a)
  • WebP: Starts with UklGR... (Header RIFF....WEBP)

3. Performance & Payload Size Trade-Offs

Base64 encoding translates every 3 bytes of binary data into 4 ASCII characters, incurring an inherent ~33% size overhead. While ideal for tiny UI icons under 10KB (reducing HTTP round-trip latency), larger images should be served as separate static assets with HTTP caching headers.

Converting Files to Base64 in Code

// JavaScript Browser FileReader API
function fileToBase64(file) {
    return new Promise((resolve, reject) => {
        const reader = new FileReader();
        reader.readAsDataURL(file);
        reader.onload = () => resolve(reader.result);
        reader.onerror = error => reject(error);
    });
}

# Python 3
import base64
with open("icon.png", "rb") as image_file:
    b64_bytes = base64.b64encode(image_file.read())
    data_uri = f"data:image/png;base64,{b64_bytes.decode('utf-8')}"

Base64 Image FAQ

Q: Can Base64 images be cached by the browser?

A: When embedded inline inside HTML or CSS, Base64 images are cached as part of that parent file. They cannot be cached independently like standalone static image URLs.

Q: Is my image data uploaded to external servers?

A: No. Base64 decoding and rendering occur using browser V8 memory and HTML Canvas APIs completely offline.
