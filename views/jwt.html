Developer Guide: Understanding JSON Web Tokens (RFC 7519)

JSON Web Token (JWT) is an open standard (RFC 7519) defining a compact, self-contained method for securely transmitting claims between parties as a JSON object.

1. JWT Anatomy

A JWT string consists of three distinct components joined by periods (Header.Payload.Signature).

2. Symmetric (HS256) vs. Asymmetric (RS256)

HS256 uses a shared secret key. RS256 uses asymmetric RSA public/private key pairs.

3. Critical JWT Security Best Practices

Never store raw passwords or secrets in JWT payloads, as Base64Url is plain text encoding, not encryption.

JWT Security FAQ

Q: Is Base64Url decoding the same as decrypting?

A: No. Base64Url is plain text encoding for URL transport.
