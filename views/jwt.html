Developer Guide: Understanding JSON Web Tokens (RFC 7519)

JSON Web Token (JWT) is an open standard (RFC 7519) defining a compact, self-contained method for securely transmitting claims between parties as a JSON object. Signed using cryptographic secrets (HMAC) or public/private key pairs (RSA, ECDSA), JWTs serve as the foundation of modern OAuth 2.0 and OpenID Connect (OIDC) authentication frameworks.

1. JWT Anatomy & Base64Url Encoding

A JWT string consists of three distinct components joined by periods (Header.Payload.Signature):

  • Header: Specifies token type ("typ": "JWT") and signing algorithm (e.g. HS256 or RS256).
  • Payload: Contains standard registered claims (sub, iss, exp, nbf, iat) and custom user claims.
  • Signature: Cryptographic hash created by signing base64Url(Header) + "." + base64Url(Payload) using a secret key or private key.

2. Symmetric (HS256) vs. Asymmetric (RS256/ES256)

HS256 (HMAC with SHA-256): Uses a single secret key shared between auth server and resource server. Ideal for monolithic applications.

RS256 (RSA Signature with SHA-256): Uses an asymmetric RSA key pair. The auth server signs tokens using the private key, while microservices verify tokens using the public key (published via JWKS endpoints).

3. Critical JWT Vulnerabilities to Avoid

  • The "none" Algorithm Attack: Attackers alter token headers to "alg": "none" to bypass signature verification if server checks are missing.
  • Secret Leakage in Payloads: Payloads are only Base64Url encoded, NOT encrypted. Never place passwords or credit card numbers in a JWT.
  • Missing Expiration (exp): Tokens without expiration persist indefinitely if compromised. Always set reasonable lifetimes (e.g., 15–60 minutes).

JWT Verification in Backend Languages

// Node.js (jsonwebtoken)
const jwt = require('jsonwebtoken');
const token = 'eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...';
try {
    const decoded = jwt.verify(token, 'your-256-bit-secret');
    console.log(decoded.sub);
} catch(err) {
    console.error('Invalid token verification:', err.message);
}

# Python (PyJWT)
import jwt
try:
    payload = jwt.decode(token, "your-256-bit-secret", algorithms=["HS256"])
    print(payload["sub"])
except jwt.ExpiredSignatureError:
    print("Token has expired")

JWT Security FAQ

Q: Is Base64Url decoding the same as decrypting?

A: No. Base64Url is plain text encoding for URL transport. Anyone with access to the token string can decode and read the payload unless JWE (JSON Web Encryption) is used.

Q: Why is offline client-side JWT decoding safer?

A: Public online decoders that log tokens on remote servers pose significant session hijack risks. Parse Utils executes 100% locally in your browser memory.
